# くれよん 求人特設サイト（地元で働こう！この街で「やりたい」を発見！）

情報誌くれよん 12月号連動企画「くれよんがおすすめする10社」の特設サイト（サンプル）。

- `index.html` … 一覧ページ（2列×5段・10社）
- `company.html?id=番号` … 企業詳細ページ（写真・本文約100文字・ポイント3つ・会社概要・募集概要・WEB応募ボタン・QRコード）
- `data/companies.js` … 10社のデータ。**ここだけ書き換えれば一覧と詳細の両方に反映される**

## 本番にするときにやること
1. `data/companies.js` を実際の掲載企業の内容・写真・応募URLに差し替える（写真は `images/` フォルダに置いて相対パスで指定）
2. `index.html` と `company.html` の「サンプル表示」の帯と `<meta name="robots" content="noindex, nofollow">` を消す

元デザインは Gemini（2026-10-19「情報誌の表紙枠分割と提案方法」）で作成したものを反映。
